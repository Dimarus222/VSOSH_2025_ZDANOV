# Кадетский Парламент — сайт с админ-панелью

Бэкенд на Go, контент хранится в SQLite как JSON-поля, есть админка с
логином, редактированием всех разделов сайта и загрузкой файлов/картинок.

Все файлы лежат в корне репозитория одним списком — никаких вложенных
папок, чтобы было удобно загружать через веб-интерфейс GitHub
("Add file → Upload files", просто перетащить всё сразу).

## Файлы в репозитории

```
main.go, go.mod          — backend (всё в одном файле)
index.html, app.js         — публичный сайт
admin.html, admin.js        — админ-панель
1.jpg, 1.doc, van.jpg, ...   — оригинальные фото и документы сайта
Dockerfile, railway.toml      — сборка и деплой на Railway
README.md, .gitignore
```

## Как залить на GitHub (без папок)

1. Зайди на github.com → New repository → назови как хочешь → Create.
2. На странице репозитория нажми **Add file → Upload files**.
3. Выдели ВСЕ файлы из распакованного архива (Ctrl+A / Cmd+A) и перетащи
   их в окно загрузки одним разом.
4. Внизу нажми **Commit changes**.

Никаких папок создавать не нужно — все файлы просто лежат рядом друг с другом.

## Деплой на Railway

1. railway.app → **New Project → Deploy from GitHub repo** → выбери репозиторий.
   Railway сам увидит `Dockerfile` и соберёт образ.
2. Добавь **Volume**: Settings → Volumes → Add Volume, mount path `/app/data`.
   Это обязательно — иначе база данных и загруженные файлы будут стираться
   при каждом новом деплое.
3. В **Variables** задай:
   - `ADMIN_USER` — логин администратора
   - `ADMIN_PASSWORD` — пароль администратора (обязательно смени, иначе
     будет использован пароль по умолчанию `changeme123`, о чём сервер
     напишет в логах при первом запуске)
4. Deploy. Settings → Networking → Generate Domain — получишь публичную ссылку.

После первого запуска в базе будет админ и весь текущий контент сайта —
тексты, фото, документы, всё как было раньше.

## Доступ к админке

`https://ваш-домен/admin/` — вход под `ADMIN_USER` / `ADMIN_PASSWORD`.

Там можно редактировать: главный баннер и блок «О парламенте», историю
(таймлайн/достижения/галерею), карточки «Лучшие кадеты» (с загрузкой фото),
направления деятельности и цитату, документы (обложка + файл), контакты,
и сменить пароль администратора.

## Локальный запуск (нужен Go 1.22+ и интернет для сборки)

```bash
go mod tidy
go run .
```

Сайт: http://localhost:8080
Админка: http://localhost:8080/admin/

## Безопасность

- Пароль хранится как bcrypt-хеш.
- Сессии — HttpOnly cookie, срок жизни 7 дней.
- Загрузка файлов ограничена типами `.jpg .jpeg .png .webp .gif .doc .docx .pdf`
  и размером 15 МБ.
- Обязательно смени `ADMIN_PASSWORD` перед тем как давать доступ кому-либо.
